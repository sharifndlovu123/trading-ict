# Microstructure library (full texts)

Full texts behind `references/orderflow.md`. PDFs/EPUBs here are **git-ignored** (copyrighted; keep local only).
Name files `NN-firstauthor-short-title.pdf` so they sort in reading order. Extract text with
`pdftotext -f <first> -l <last> "<file>" -` and pull only the pages you need.
